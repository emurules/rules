# EMU Rules — English Mafia Unified

EMU is an independent, English-language competitive Mafia ruleset,
independently written and owned, and compatible with FIIM tournament
rules.

## What's here

- [`RULES.md`](RULES.md) — the ruleset (canonical).
- [`DIVERGENCES.md`](DIVERGENCES.md) — where EMU diverges from FIIM tournament
  rules, and why.

## Canonical source

This repository is the single source of truth for the EMU Rules. The website
(https://emurules.com) and the [EMU book](https://howto.emurules.com) both consume these rules; they do not
hold their own authoritative copies. If a version elsewhere ever differs from
this repository, this repository is authoritative.
